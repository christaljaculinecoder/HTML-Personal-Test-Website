```markdown
# ✅ Task — Personal Profile Page (Semantic HTML)

## 🎯 Objective

**Build a well-structured personal profile webpage using semantic HTML.**
**The goal is to demonstrate correct document structure, meaningful tags, and proper attribute usage.**

---

## 📌 Task Description

**Create a single HTML file that represents a personal profile page.**
**The page must use semantic HTML elements and be organized into clearly defined sections.**

---

## 🛠 Requirements

### ✅ 1. Basic HTML Structure (Mandatory)

**Your file must include:**

- **<!DOCTYPE html>**
- **<html>**
- **<head>**
- **<body>**
- **Proper meta tags:**
  - **charset**
  - **viewport**
- **Meaningful page title**

---

### ✅ 2. Header Section

**Use a semantic <header> element that includes:**

- **Your name using a heading tag**
- **Your role/title (example: Student, Developer, Designer)**

---

### ✅ 3. About Section

**Use <section> to create an About area that contains:**

- **A paragraph introducing yourself**
- **At least 3–4 sentences**

---

### ✅ 4. Skills Section

**Use another semantic <section> that contains:**

- **A heading**
- **An unordered list**
- **Minimum 5 skills**

---

### ✅ 5. Contact Section

**Use a semantic <section> that includes:**

- **Email and phone (dummy data)**
- **A LinkedIN Profile link using <a>**
- **Proper attributes (href, etc.)**

---

### ✅ 6. Semantic Structure

**You must use:**

- **<header>**
- **<main>**
- **<section>**

**Content should be logically organized.**

---

## 🚫 Restrictions

- **No CSS or JavaScript required**
- **No random tags outside structure**
- **Do not copy from the internet**
```
